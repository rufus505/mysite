## Features

- ダークテーマ／ライトテーマの切り替え
- 選択したテーマのブラウザ内保存
- PC・タブレット・スマートフォンに対応したレスポンシブデザイン
- スクロールに合わせた控えめな表示アニメーション
- モバイル向けナビゲーションメニュー
- キーボード操作を考慮したフォーカス表示と本文スキップリンク
- OSの「視差効果を減らす」設定に応じたアニメーション制御

## Tech Stack

- **HTML5** — ページの構造・コンテンツ
- **CSS3** — レイアウト、配色、レスポンシブ対応、アニメーション
- **JavaScript** — テーマ切り替え、ナビゲーション、スクロール演出
- **GitHub Pages** — 静的Webサイトのホスティング

外部のビルドツールやフレームワークを使わず、HTML・CSS・JavaScriptを中心に構成した静的サイトです。

## Project Structure

```text
mysite/
├── index.html       # ページ構造・メタ情報・構造化データ
├── style.css        # デザイン・レスポンシブ対応
├── script.js        # テーマ切り替え・言語切り替え・UI制御
├── favicon.png      # サイトアイコン
├── ogp.svg          # SNS共有用画像
├── robots.txt       # クローラー向けの巡回ルール・サイトマップ案内
├── sitemap.xml      # 検索エンジン向けサイトマップ
└── README.md        # プロジェクトの説明
```

## SEO

- ページタイトルとメタディスクリプションを設定
- canonical URLで正規URLを明示
- OGP・X Cardの共有情報を設定
- JSON-LDでWebSiteとPersonの基本情報を記述
- `robots.txt` でサイトマップの場所を案内
- `sitemap.xml` に公開中のトップページを登録

現在は1ページ構成のため、サイトマップにはトップページのみを掲載しています。独立した記事・プロジェクトページを追加した場合は、そのURLもサイトマップに追加してください。

## Run Locally

このサイトは静的サイトなので、ビルドやパッケージのインストールは必要ありません。

1. このリポジトリをクローンします。

   ```bash
   git clone https://github.com/rufus505/mysite.git
   ```

2. `mysite` ディレクトリを開きます。
3. `index.html` をブラウザで開くと、サイトを確認できます。

## Deployment
